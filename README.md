# java-lotto-precourse - [BE] 조상준

# 1. 어플리케이션 정의

간단한 로또 발매기를 구현한다.

---

## 1.1 용어 사전

### 로또 Lotto

| 용어                         | 정의                                        | 설명                                         |
|----------------------------|-------------------------------------------|--------------------------------------------|
| 로또 (Lotto)                 | 1부터 45까지의 서로 다른 6개의 숫자로 구성된 복권 한 장을 의미한다. | 해당 로또는 고유한 6개의 번호 조합을 가지며, 항상 오름차순으로 정렬된다. |
| 로또 묶음 (Lottos)             | 사용자가 구매한 모든 로또들을 의미한다.                    |                                            |
| 로또 번호 (Lotto Number)       | 로또 한 장에 위치하는 **개별 번호**를 의미한다.             | 1 이상 45 이하의 자연수                            |
| 로또 구입 금액 (Purchase Amount) | 사용자가 로또를 구매하기 위해 지불한 금액을 의미한다.            | 1000원 단위만 가능하다.                            |

### 당첨 Winning

| 용어                       | 정의                                  | 설명                                            |
|--------------------------|-------------------------------------|-----------------------------------------------|
| 당첨 번호 (Winning Numbers)  | 당첨 결과를 판단하기 위한 6개의 번호 조합을 의미한다.     | 개별번호가 아닌, 6개의 번호 조합이다.                        |
| 보너스 번호 (Bonus Number)    | 당첨 순위를 결정할 때, 사용되는 보너스 번호를 의미한다.    | 현 어플리케이션에서, 2등을 판별할 때 사용되는 번호이다.              |
| 순위 (Rank)                | 당첨 결과의 순위와 속성값을 의미한다.               | 1등에서 5등까지 존재한다.                               |
| 당첨 기준 (Winning Criteria) | 당첨의 순위를 결정하는 기준을 의미한다.              | 현 어플리케이션에서는 총 5등까지의 당첨 기준을 가지고 있다. (기능 명세 참고) |
| 당첨 금액 (Prize Money)      | 각 순위별로 지급되는 상금 금액을 의미한다.            | 1등(20억), 2등(3천만), 3등(150만), 4등(5만), 5등(5천)    |
| 당첨 결과 (Winning Result)   | 각 등수별로 몇개의 로또가 당첨되었는지 집계한 결과를 의미한다. | 일치 개수와 로또의 개수 쌍으로 구성된다. (예: 3개 일치 - 1장)       |
| 당첨 수익률 (Profit Rate)     | (총 당첨금 / 총 구매금액) x 100을 의미한다.       | 수익률은 소수점 둘째 자리에서 반올림한다.                       |

### 주체

| 용어                       | 정의                                   | 설명                              |
|--------------------------|--------------------------------------|---------------------------------|
| 로또 발매기 (Lotto Machine)   | 구매 금액에 따라 지정된 개수의 로또를 발행하는 주체를 의미한다. | 구입 금액을 1000으로 나눈 값이 지정된 금액이 된다. |
| 당첨 판별기 (Winning Checker) | 로또와 당첨 번호를 비교하여 순위를 결정하는 주체를 의미한다.   |                                 |

# 2. 기능 명세서

---

## 1. 입력 기능

### 1-1. 로또 구입 금액 입력

- [x]  사용자는 로또 구입 금액을 입력한다.
- [x]  ⚠️ 검증. 로또 구입 금액 입력 문자열 검증
    - [x]  입력 문자열은 숫자여야 한다.
- [x]  로또 구입 금액을 문자열에서 숫자로 변환하여 저장한다.
- [x]  ⚠️ 검증. 로또 구입 금액 검증
    - [x]  금액은 1000원 이상의 자연수이며, 1000원 단위여야 한다.

### 1-2. 당첨 번호 입력

- [ ]  사용자는 쉼표로 구분된 6개의 당첨 번호를 입력한다.
- [ ]  ⚠️ 검증. 당첨 번호 입력 문자열 검증
    - [ ]  입력 문자열은 숫자(6개)와 쉼표(5개)가 번갈아 나오는 포멧을 준수해야 한다.
- [ ]  당첨 번호 입력 값을 쉼표를 기준으로 분리하여 저장한다.
- [ ]  ⚠️ 검증. 당첨 번호 검증
    - [ ]  개별번호는 1~ 45 사이의 자연수여야 한다.
    - [ ]  개별 번호 사이에 중복이 없어야 한다.
    - [ ]  당첨 번호는 총 6개여야 한다.

### 1-3. 보너스 번호 입력

- [ ]  사용자는 1~45 사이의 보너스 번호를 하나 입력한다.
- [ ]  ⚠️ 검증. 보너스 번호 입력 문자열 검증
    - [ ]  입력 문자열은 숫자여야 한다.
- [ ]  보너스 번호를 문자열에서 숫자로 변환하여 저장한다.
- [ ]  ⚠️ 검증. 보너스 번호 검증
    - [ ]  보너스 번호는 1~ 45 사이의 자연수여야 한다.
    - [ ]  보너스 번호는 당첨 번호와 중복되면 안된다.

## 2. 로또 발행 기능

### 2-1. 구매 수량 계산

- [ ]  구매 금액을 기반으로 발행 가능한 로또 장 수를 계산한다.
    - 첨언. `로또 발행 수 = 구입금액 / 1000`

### 2-2. 단일 로또 번호 생성

- [ ]  1~45사이의 중복되지 않는 무작위 값 6개를 생성한다.
- [ ]  ⚠️ 검증. 생성된 로또 번호 검증
    - [ ]  로또 개별 번호는 총 6개여야 한다.
    - [ ]  로또 내부에 중복된 개별 번호가 없어야 한다.
    - [ ]  1~45의 범위를 만족하는 자연수이어야 한다.

### 2-3. 로또 여러 장 생성

- [ ]  로또 발행 개수에 맞게, 2-2를 반복 실행한다.
- [ ]  모든 발행이 완료된 이후, 모든 로또를 저장한다.

### 2-4. 로또 번호 정렬

- [ ]  생성된 모든 로또의 번호를 오름차순으로 정렬한다.

## 3. 당첨 판별 기능

- [ ]  모든 로또에 대해 아래 3가지 과정을 반복한다.

### 3-1. 번호 일치 개수 계산

- [ ]  각 로또의 개별 번호와 당첨 개별 번호가 서로 일치하는 개수를 구한다.

### 3-2. 보너스 번호 일치 여부 확인

- [ ]  보너스 번호가 포함되어 있는지 확인한다.

### 3-3. 당첨 등수 결정

- [ ]  해당 로또(한장)의 등수를 결정한다.

## 4. 당첨 결과 결정

### 4-1. 당첨 결과 집계

- [ ]  각 로또의 등수를 세어, 등수별 개수를 저장한다.

### 4-2. 총 수익률 계산

- [ ]  당첨된 금액을 모두 합산하고 저장한다.
- [ ]  총 당첨금 대비 구매가격의 수익률을 계산한다. (%으로 계산한다.)
    - 첨언. 수익률은 소수점 둘째 자리에서 반올림한다.

## 5. 결과 값 출력

- [ ]  로또 발행 개수를 출력한다.
    - 예시: `8개를 구매했습니다.`
- [ ]  전체 로또 목록을 출력한다.
    - `[8, 21, 23, 41, 42, 43]`...
- [ ]  당첨 통계를 출력한다.
    - 예시: `3개 일치 (5,000원) - 1개` …. `6개 일치 (2,000,000,000원) - 0개`
- [ ]  총 수익률을 출력한다.
    - 에시: `총 수익률은 62.5%입니다.`

# 3. 어플리케이션 발생 예외 정리 ⚠️ 

---

- 입력 값에 대한 예외는, 에러메시지 출력 후 재입력받도록 설계한다.

### 1. 로또 구입 금액 입력시, 발생 예외

**입력 문자열**

- [x]  입력 값이 Null이거나 Blank인 경우 예외가 발생한다.
    - [ERROR] 로또 구입 금액은 null이거나 blank일 수 없습니다.
- [x]  숫자가 아닌 경우 예외가 발생한다.
    - [ERROR] 로또 구입 금액은 숫자를 입력해야 합니다.

**구입 금액**

- [x]  1000원 이상이 아닌 경우 예외가 발생한다.
    - [ERROR] 로또 구입 금액은 1000원 이상이어야 합니다.
- [x]  1000원 단위가 아닌 경우 예외가 발생한다.
    - [ERROR] 로또 구입 금액은 1000원 단위여야 합니다.

### 2. 당첨 번호 입력시, 발생 예외

**입력 문자열**

- [x]  입력 값이 Null이거나 Blank인 경우 예외가 발생한다.
    - [ERROR] 당첨 번호 입력 값은 null이거나 blank일 수 없습니다.
- [ ]  입력된 문자열 내부에, 연속된 쉼표가 있는 경우 예외가 발생한다.
    - [ERROR] 당첨 번호 입력 값은 숫자 6개와 쉼표 5개가 번갈아 나오는 형식이어야 합니다.
- [ ]  입력된 문자열 맨앞/뒤에 쉼표가 있는 경우 예외가 발생한다.
    - [ERROR] 당첨 번호 입력 값은 숫자 6개와 쉼표 5개가 번갈아 나오는 형식이어야 합니다.
- [ ]  쉼표의 개수는 5개가 아닌 경우 예외가 발생한다.
    - [ERROR] 당첨 번호 입력 값은 숫자 6개와 쉼표 5개가 번갈아 나오는 형식이어야 합니다.

**당첨 번호**

- [ ]  당첨 번호가 숫자가 아닌 경우 예외가 발생한다.
    - [ERROR] 로또 번호는 1부터 45 사이의 자연수여야 합니다.
- [ ]  당첨 번호의 개별 번호가 음수인 경우 예외가 발생한다.
    - [ERROR] 로또 번호는 1부터 45 사이의 자연수여야 합니다.
- [ ]  당첨 번호의 개별 번호가 1부터 45 사이의 자연수가 아닌 경우 예외가 발생한다.
    - [ERROR] 로또 번호는 1부터 45 사이의 자연수여야 합니다.
- [ ]  당첨 번호의 개별 번호가 서로 중복되는 경우 예외가 발생한다.
    - [ERROR] 중복된 당첨 번호가 존재합니다.
- [ ]  당첨 번호의 개수가 6개가 아닌 경우 예외가 발생한다.
    - [ERROR] 당첨 번호는 6개여야 합니다.

### 3. 보너스 숫자 입력시, 발생 예외

**입력 문자열**

- [ ]  입력 값이 Null이거나 Blank인 경우 예외가 발생한다.
    - [ERROR] 보너스 숫자는 null이거나 blank일 수 없습니다.
- [ ]  숫자가 아닌 경우 예외가 발생한다.
    - [ERROR] 보너스 숫자는 숫자여야 합니다.

**보너스 번호**

- [ ]  보너스 번호가 음수인 경우 예외가 발생한다.
    - [ERROR] 보너스 번호는 1부터 45 사이의 자연수여야 합니다.
- [ ]  보너스 번호가 1부터 45 사이의 자연수가 아닌 경우 예외가 발생한다.
    - [ERROR] 보너스 번호는 1부터 45 사이의 자연수여야 합니다.
- [ ]  보너스 번호가 당첨 번호와 중복되면 예외가 발생한다.
    - [ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.
